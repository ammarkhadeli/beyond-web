The ISS travels around Earth much faster than Earth's daily rotation. At the game's 408 km circular orbit, `sqrt(mu / radius)` gives approximately 7.67 km/s and `2π sqrt(radius³ / mu)` gives approximately 92.6 minutes. These are calculated values from the game's constants, not real-time measurements. Earth's surface rotates once per sidereal day; only a geostationary orbit matches its angular rotation while remaining over one longitude.

Resource percentages, science scores, payload budget credits, damage thresholds, event schedules and task-completion rewards are balancing values. A fictional modern training vehicle is not a certified Dragon, Orion, or NASA specification. Historical vehicles use selected source-informed parameters with simplified guidance. The trajectory display predicts unpowered motion from the current numerical state; future guided maneuvers can change that path.

## Other environment sources

[NOAA solar calculation equations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF) inform an approximate solar direction for a chosen UTC scenario time. The calculation controls illumination; it is not a navigation ephemeris. [Open-Meteo documentation](https://open-meteo.com/en/docs) supports the optional site-coordinate current-weather request. The response is a weather-model estimate, not a launch clearance or satellite cloud map. Failed, invalid or stale responses select a labeled clear-weather preset. The automated tests mock these responses; successful live access has not been verified in the restricted environment.
