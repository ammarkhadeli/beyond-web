Problem & audience

Mission design for learners

A mission is a connected set of decisions. Students need to see how a design changes the flight, the scientific work and the resources left for recovery.

Choose

Set a destination and payload. Balance equipment, power, mass, communications and reserves.

Experience

Operate the cockpit and worksite. See a decision become a practical constraint.

Understand

Use short guidance and optional physics explanations. Review outcomes and try another design.

Challenge: Space Mission Design Game · Team: Batata Warriors.

Gameplay loop

Mission workflow

01

Plan

Choose payload and reserves.

02

Review

Check mass, power, budget and launcher.

03

Fly

Launch, transfer, approach.

04

Work

Operate equipment and resolve a fault.

05

Recover

Return the crew and results.

More equipment adds capability and mass. Extra reserves change launch mass. Instrument work consumes power. Fault recovery competes with mission reserves.
Winning requires the science objective and safe recovery. Time acceleration is visible; it advances the numerical simulation.
Balancing values are labeled separately from NASA facts03 / 07

Two mission routes

ISS and lunar routes

International Space Station

Dock, enter the station, install the experiment, record observations and secure results.

Return route: undock → deorbit → entry → recovery

Moon

Land, deploy instruments, collect a sample and stow the science before ascent.

Return route: ascent → rendezvous → Earth return → recovery

The concept originated with the user. AI assisted development, documentation and original modeling code. No Azure AI or LLM runs the mission. Optional browser speech reads authored captions; historical recordings keep separate credits.
